# 分组判断规则（对 BLOCK_RULE_20261012.md 的修改）

写定时间：2026-10-13 17:33 EDT（2026-10-13T21:33Z）。此时**没有任何评审交回评分表或任何判断**：邮箱里没有来自 R3或 R4 的带附件来信，评审线程里没有任何带判断内容的来信。由第一作者于 10/13 决定。`PAIR_RULE_20261010.md`、`BLOCK_RULE_20261012.md` 原文不动；本文件没有改到的条款照旧。

## 为什么改

10/12 至 10/13 邀请的 23 位独立专家里，1 位答应，9 位婉拒。一位有经验的建模者看过示例后回信说：要判得准确，每道题需要 30 到 40 分钟，一块（11 到 12 题）的工作量被低估了；他建议把题分给更多人，再报告统计汇总。按他的估计一块要 5.5 到 8 小时，在几天内找到愿意无偿判完一整块的人不现实。所以把每人的最小工作量从一块减到一组（2 到 3 道题）。

## 规则

1. **分组**。每一块按题目册顺序每三道题分成一组，一块的最后一组可以只有两道题。只由 `blocks_20261012/blocks.json` 的题目顺序决定。共 12 组：
   - A1：P01–P03，A2：P04–P06，A3：P07–P09，A4：P10–P12；
   - B1：P13–P15，B2：P16–P18，B3：P19–P21，B4：P22–P23；
   - C1：P24–P26，C2：P27–P29，C3：P30–P32，C4：P33–P34。
2. **新评审每人至少判一组**，可以自愿多判几组。分配顺序：每次分配当前"已分配的新评审人数最少"的那一组（R4 已分配 C1 至 C4，算在内；R3 按题目册顺序判全部，不算在内），人数相同时取题目册里靠后的一组。所以依次是 B4、B3、B2、B1、A4、A3、A2、A1，然后 C4、C3、C2、C1，再回到 B4。评审编号从 R5 起，按确认独立性声明的先后。
3. **资格按组算**（改 BLOCK 规则第 3 条）。一位评审对某一组有资格，是指这一组的每个程序他都给了判断。R3 和 R4 的评分表按同样的办法逐组看：R4 拿到的是 C 块，他判完 C 块里的哪几组，就对哪几组有资格；R3 同理。
4. **每组取两位**（改 BLOCK 规则第 4 条）。每一组在有资格的评审里取两位：满足预注册全部独立性条件并已确认声明的优先，其余按这一组评分表的交回先后。两位里编号小的记为第一判断，编号大的记为第二判断。其余有资格的评审对这一组是附加评审。
5. **同组的两位不能来自同一个研究组**（新增）。同一个研究组、师生或近三年合写过论文的两位评审都对同一组有资格时，只取先交回的一位，另一位对这一组是附加评审。受邀人之间已知的这类关系记在交接文件里，在第一份评分表交回之前写定。
6. **确定时刻**不变：2026-10-18 12:00 美东时间，对每一组一次定下两位，之后不改。
7. **不做分歧讨论、新评审不做规则通读**，不变。
8. **某一组只有一位有资格**：由这一位的判断给出标签，这一组不进一致性系数。**某一组没有人有资格**：由没有写过也没有评阅过规则的共同作者盲判，论文写明这一组不独立。论文按组说明各是哪一种情况，并给出三种情况各有多少个程序。
9. **统计汇总**。一致性系数照预注册第 7 节的算法，在有两位判断的程序上计算；第一判断、第二判断各由多位评审的判断拼成。另外报告：参加的评审人数、每人判了几组几个程序、每个程序有几位评审判过、两位判断一致的程序所占的比例。这些计数是登记之外的描述性汇总，照此标明。
10. **如实报告工作量**。论文写明邀请了多少人、多少人答应、每位评审自己报告的用时（交回时询问，不强求），以及有专家认为预估用时偏低这一点。

## 与预注册的差别（都作为偏离报告）

- BLOCK 规则里列的各项不变：评审多于两位，每人只判一部分；两列判断各由多人拼成；没有分歧讨论，新评审没有做规则通读；确定时刻为 10/18 中午。
- 新增：最小工作量从一块改为一组；资格和"每部分取两位"都按组算；同一组的两位不能来自同一个研究组。
- 抽样、盲法、判断标准、评分表各列、错误类别、分析脚本都没有改。
